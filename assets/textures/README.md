# 坦克贴图说明 / Tank Textures

## 贴图文件 / Texture Files

游戏需要以下贴图文件：

### 必需的贴图 / Required Textures

1. **player_tank.png** - 玩家坦克贴图 (40x40 像素)
2. **enemy_tank.png** - 敌人坦克贴图 (35x35 像素)

## 贴图规格 / Texture Specifications

- **格式 / Format**: PNG with transparency
- **玩家坦克 / Player Tank**: 40x40 pixels, 绿色系 / green color scheme
- **敌人坦克 / Enemy Tank**: 35x35 pixels, 红色系 / red color scheme
- **方向 / Orientation**: 默认朝上 / Default facing upward

---

**注意 / Note**: 如果没有贴图文件，游戏将使用纯色方块作为坦克的视觉表现。
If texture files are not present, the game will fall back to solid color squares for tank visuals.
