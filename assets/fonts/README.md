# 字体文件说明 / Font Files

## 思源黑体 (Source Han Sans)

本游戏使用 Adobe 的思源黑体作为 UI 字体。

### 下载字体 / Download Font

请从以下链接下载思源黑体（简体中文版本）：

**官方 GitHub 仓库：**
https://github.com/adobe-fonts/source-han-sans/releases

### 安装说明 / Installation

1. 下载 `SourceHanSansCN-Regular.otf` 文件
2. 将文件放置在此目录中（`assets/fonts/`）
3. 确保文件名为 `SourceHanSansCN-Regular.otf`

### 文件结构 / File Structure

```
assets/
└── fonts/
    └── SourceHanSansCN-Regular.otf  (需要下载 / Need to download)
```

### 许可证 / License

思源黑体使用 SIL Open Font License 1.1 许可证。
详情请访问：https://github.com/adobe-fonts/source-han-sans/blob/release/LICENSE.txt

---

如果无法下载字体文件，游戏将无法正常显示文字。
If the font file is not available, the game will not display text properly.
